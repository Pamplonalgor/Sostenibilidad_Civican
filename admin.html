Conectar Supabase

Estado del Almacenamiento

Por defecto, el sitio web funciona en modo local (LocalStorage) para que puedas probar la aplicación de inmediato sin configurar nada. Si quieres usar Supabase, introduce las credenciales de tu proyecto a continuación. Los datos se persistirán en la nube.

SQL Script para tu base de datos Supabase

Copia y pega este script en el editor SQL de tu panel de Supabase para inicializar las tablas necesarias con las columnas correspondientes en segundos:

Mostrar Script SQL de Tablas 
-- Tabla de Talleres
create table talleres (
  id uuid default gen_random_uuid() primary key,
  created_at timestamp with time zone default now() not null,
  title text not null,
  description text,
  age_range text,
  instructor text,
  schedule text,
  capacity integer,
  category text,
  image_url text
);

-- Tabla de Torneos
create table torneos (
  id uuid default gen_random_uuid() primary key,
  created_at timestamp with time zone default now() not null,
  title text not null,
  description text,
  game text,
  schedule text,
  rules text,
  prizes text,
  max_players integer,
  age_range text,
  image_url text
);

-- Tabla de Conferencias
create table conferencias (
  id uuid default gen_random_uuid() primary key,
  created_at timestamp with time zone default now() not null,
  title text not null,
  description text,
  speaker text,
  speaker_company text,
  speaker_image text,
  schedule text,
  room text,
  age_range text,
  image_url text
);

-- Tabla de Juegos Offline
create table juegos_offline (
  id uuid default gen_random_uuid() primary key,
  created_at timestamp with time zone default now() not null,
  title text not null,
  description text,
  type text,
  location text,
  schedule text,
  capacity text,
  age_range text,
  image_url text
);

Paso 1

Branding y Concepto Visual

Todo proyecto empieza definiendo la identidad de marca. Diseñamos un evento tecnológico/STEAM enfocado a jóvenes de 6 a 18 años.

  • Paleta de colores: Estilo "Dark Mode" espacial con acentos de luces neón en Cyan, Morado, Verde y Naranja.
  • Tipografía: Estilos de letra geométricos y modernos (Google Fonts: Space Grotesk, Outfit e Inter).
  • Logotipo SVG: Vector interactivo que fusiona un mando de consola con corchetes de código de programación `< />`.
Prompt del Profesor
"Branding de un evento orientado a niños de 6 a 18 años pero tecnológico/Steam. Nombre del evento es Navarra Code & Game. Pon un logo atractivo y dinámico en formato SVG."
Paso 2

Arquitectura de Archivos Estática

Para mantener la sencillez técnica, creamos una estructura de desarrollo clásica de desarrollo web front-end utilizando HTML5, CSS3 y JavaScript moderno:

  • 📁 index.html: Landing/cuenta atrás.
  • 📁 talleres.html: Talleres con filtros.
  • 📁 torneos.html: Competiciones gaming.
  • 📁 conferencias.html: Charlas STEAM.
  • 📁 juegos.html: Actividades offline.
  • 📁 admin.html: Gestión de contenidos.
  • 📁 css/style.css: Estilos CSS.
  • 📁 js/db.js: Capa base de datos.
Prompt del Profesor
"Haremos una web con html, css y javascript simple, sin react ni next.js. Tendrá Landing/Home, Talleres, Torneos, Conferencias, Juegos Offline y un Panel de Administrador."
Paso 3

Landing Page & Cuenta Atrás

La pantalla de bienvenida incluye un gancho visual potente: un **temporizador en cuenta atrás gigante** hacia el Viernes 20 de Noviembre de 2026.

  • index.html: Estructura Hero, rejilla con accesos directos a las páginas públicas y pie de página.
  • js/countdown.js: Lógica matemática con `setInterval()` que resta la fecha objetivo de la actual, calculando los Días, Horas, Minutos y Segundos restantes de forma dinámica en milisegundos.
Prompt del Profesor
"La landing de inicio debe tener una cuenta atrás del evento que empieza el viernes 20 de Noviembre. Haz que sea visualmente espectacular, con efectos neón de fondo."
Paso 4

Tarjetas de Actividades y Filtros

Creamos 4 páginas temáticas muy atractivas visualmente que renderizan dinámicamente las actividades.

  • Filtros Dinámicos: Botones para filtrar actividades por rango de edad (6-10, 11-14 y 15-18 años) o tipo, actualizando las tarjetas en el DOM al instante y de forma fluida.
  • Modales de Detalle: Al hacer clic en "Info", se abre una ventana emergente de cristal (glassmorphism) que detalla el ponente, reglas, horarios, aforo y simula la inscripción.
Prompt del Profesor
"Crea las vistas de talleres, torneos y conferencias. Añade un filtro dinámico por edades, y un botón en cada tarjeta que abra un modal detallando la actividad y simule el registro."
Paso 5

Base de Datos Híbrida Inteligente

Para que el proyecto funcione de inmediato sin obligar a configurar bases de datos online en el primer día, diseñamos la capa js/db.js:

  • LocalStorage Fallback: Si no hay credenciales de Supabase en local, la web lee/escribe en el LocalStorage del navegador utilizando datos de prueba precargados.
  • Versión de Mocks: Un identificador de versión (`v2`) en el JS fuerza el refresco automático de los datos en el navegador si el profesor añade nuevas actividades.
Prompt del Profesor
"Prepara la base de datos para usar Supabase en producción, pero haz que si no está configurada, use LocalStorage con mock data inicial para que funcione nada más abrir la web."
Paso 6

Integración y Despliegue en la Nube

Cuando decidimos pasar el proyecto a producción, conectamos el servicio de base de datos relacional **Supabase**:

  • SQL Editor: Ejecutamos un script en el panel de control de Supabase para crear las cuatro tablas con IDs automáticos de tipo UUID.
  • Conexión en Caliente: El adaptador JS detecta la URL del proyecto y la publishable (Anon) Key. Si están presentes, el backend cambia a Supabase de manera automática y transparente.
Prompt del Profesor
"sb_publishable_-JKoHcQK-R3SdyjnYUnQSQ_OFgkxkna y url https://shuehcrlyolakwkosgae.supabase.co. Haz la integración y prepara las tablas SQL correspondientes."
Paso 7

El Panel CRUD del Administrador

Por último, creamos la zona de gestión **admin.html** donde los organizadores del evento pueden administrar el catálogo completo en tiempo real.

  • Pestañas dinámicas: Cambia entre Talleres, Torneos, Charlas y Configuración sin recargar.
  • CRUD Completo: Formularios con validación en HTML5 para Crear, Visualizar, Editar (precargando la información) y Borrar registros en Supabase o LocalStorage.
  • Botón de Sincronización: Un botón que permite exportar los datos locales de prueba a Supabase con un clic.
Resumen

¿Qué hemos aprendido hoy?

Este proyecto demuestra cómo estructurar un sitio web profesional y dinámico utilizando tecnologías web nativas básicas:

  • 🚀 Navegación & Estructura: Controlar rutas y estructurar maquetación HTML semántica.
  • 🎨 Estética Moderna (CSS): Diseñar degradados, bordes neón y responsive sin Tailwind.
  • 🧠 Lógica DOM (JS): Filtrar, abrir modales e interactuar con objetos.
  • 💾 Almacenamiento (Supabase): Realizar consultas a bases de datos relacionales en la nube de manera segura.
